# 科學探索站 — 統計後台安裝說明

這個資料夾是一個小型、自帶資料庫的 PHP 統計系統，用來記錄「科學探索站」的
造訪人數、訪客 IP、大致地區，並提供一個網頁後台可以查看報表、標記可疑流量、
管理封鎖名單。不需要另外申請資料庫服務，資料存在一個 SQLite 檔案裡。

## 這個資料夾裡有什麼

| 檔案 | 用途 |
|---|---|
| `log.php` | 記錄端點，`science-station.html` 每次被打開會自動呼叫它 |
| `stats-admin.php` | 網頁後台，登入後可以看報表、管理 IP 封鎖名單 |
| `stats-config.php` | 設定檔：後台密碼、時區、是否查詢地區等 |
| `stats-lib.php` | 共用程式邏輯，`log.php` 和 `stats-admin.php` 都會用到 |
| `stats-data/` | 資料庫檔案存放處（自動建立），已用 `.htaccess` 擋掉外部直接下載 |

## 安裝步驟（適用大多數免費 / 學校 PHP 主機）

1. **確認主機支援 PHP**（多數免費空間、學校網站主機都有，通常是 PHP 7.4 以上）。
   不需要 MySQL，也不需要額外安裝套件——只要 PHP 內建的 SQLite（`pdo_sqlite`）
   有開啟即可，這是絕大多數主機的預設值。

2. **上傳檔案**：把整個 `backend` 資料夾，連同 `science-station.html`，
   一起用 FTP／主機的檔案管理員上傳到網站根目錄，維持這樣的結構：

   ```
   你的網站根目錄/
   ├── science-station.html
   └── backend/
       ├── log.php
       ├── stats-admin.php
       ├── stats-config.php
       ├── stats-lib.php
       └── stats-data/
           └── .htaccess
   ```

3. **確認資料夾可寫入**：`backend/stats-data/` 這個資料夾需要伺服器可以
   寫入（用來建立、更新 SQLite 檔案）。大多數主機預設就可以，如果後台顯示
   資料庫錯誤，到主機控制台把 `backend/stats-data/` 的權限設成 755 或 775。

4. **更換後台密碼**（很重要，預設密碼是 `science2026`）：
   - 如果你的電腦有安裝 PHP，開終端機執行：
     ```
     php -r "echo password_hash('你的新密碼', PASSWORD_DEFAULT), PHP_EOL;"
     ```
   - 沒有 PHP 環境的話，也可以先用預設密碼登入後台，之後再回來換；
     或請人代為執行上面這行指令。
   - 把印出來的一長串文字（`$2y$...` 開頭）整個複製，貼到
     `stats-config.php` 裡 `admin_password_hash` 後面的單引號中間，
     取代原本的內容。

5. **開啟後台**：瀏覽器打開 `你的網址/backend/stats-admin.php`，
   輸入密碼即可看到報表。

6. **確認記錄正常運作**：打開 `science-station.html`（正式網址），
   再回到後台重新整理，應該會看到「今天」的造訪數變成 1。
   如果一直是 0，檢查瀏覽器開發者工具的 Network 分頁，看
   `backend/log.php` 的請求有沒有成功（狀態碼應該是 204）。

## 後台看得到什麼

- 今天／近 7 天／近 30 天的造訪數與不重複 IP 數
- 近 30 天每日造訪趨勢圖
- 熱門頁面、訪客國家／地區排行
- 每支 IP 的造訪次數、首次與最近造訪時間、地區
- 「可疑」標記：同一支 IP 在 10 分鐘內造訪超過 30 次（可在
  `stats-config.php` 調整門檻），僅供參考，不會自動封鎖
- 最近造訪紀錄明細（時間、IP、地區、頁面、語言、來源網址）

## 關於「封鎖 IP」

後台的「封鎖」按鈕只是把 IP 加進一份名單，**本身不會真的擋掉對方**，
因為 `science-station.html` 是純靜態頁面。後台會自動幫你組好對應的
`.htaccess` 封鎖規則文字，你只要複製貼到網站根目錄的 `.htaccess`
檔案裡（沒有的話新建一個），伺服器才會真正拒絕該 IP 的連線。
不確定怎麼改 `.htaccess` 的話，建議先請主機商客服協助，或先備份
原本的檔案再修改。

## 隱私提醒（對象是高中以下學生時特別重要）

- 系統會記錄訪客的 IP 位址、造訪頁面與瀏覽器資訊，這些屬於個人資料，
  請只給你信任的管理者知道後台密碼，也建議在網站上放一段簡短的
  「本站會記錄匿名瀏覽數據」說明。
- 地區查詢（把 IP 轉換成國家/城市）是呼叫免費的第三方服務
  `ip-api.com`，也就是說每次有人造訪，對方伺服器會看到訪客的 IP。
  如果不想讓任何第三方服務經手 IP，可以到 `stats-config.php` 把
  `'geoip_lookup' => true` 改成 `false`，記錄功能完全不受影響，
  只是後台不會顯示地區。
- 系統不會記錄姓名、學號等個人身份資訊——問卷區塊如果之後串接
  Google 表單，那份資料是 Google 表單自己的隱私規範，跟這個統計
  後台是分開的兩件事。

## 之後要搬家（換主機）怎麼辦

因為全部都是 PHP 檔案加一個 SQLite 資料庫檔（沒有用到 MySQL），
搬家非常單純：

1. 把 `backend/` 整個資料夾（含 `stats-data/stats.sqlite`）和
   `science-station.html` 一起複製到新主機的對應位置。
2. 確認新主機一樣支援 PHP、`stats-data/` 資料夾可寫入。
3. 完成，歷史資料會完整帶過去，不需要額外轉檔或重灌。

## 免費 PHP 主機怎麼選

找關鍵字「免費 PHP 虛擬主機」，常見選項包括 InfinityFree、
000webhost、AwardSpace 等，挑選時注意兩點：

- 有支援 **PHP + SQLite**（絕大多數都有，SQLite 是 PHP 內建功能）
- 允許 PHP 對外發送 HTTP 請求（`curl`），這樣「地區查詢」才能運作；
  就算對方限制了，記錄功能還是正常，只是查不到地區而已。
